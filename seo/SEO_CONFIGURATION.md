# إعدادات SEO - SEO_CONFIGURATION

- الموقع: شات درر العرب (https://www.iraqia-chat.com)
- Canonical: بصيغة `https://www.` على كل الصفحات (ثابت).
- robots meta: `index, follow` على المحتوى؛ الصفحات المؤقتة/الأرشيف مستثناة.
- robots.txt: يسمح بالزحف ويشير إلى sitemap.xml / sitemape.xml / sitemap.txt.
- Sitemap: XML + TXT + HTML مع صور (image:image) على كل رابط.
- hreflang: غير منطبق (موقع أحادي اللغة ar).
- Redirects: الإنتاج يعيد توجيه www→non-www (يُوحّد لاحقاً مع canonical بقرار المالك).
- 404: صفحة 404 موجودة و`noindex` ضمن القالب.
- Structured Data: BreadcrumbList + WebSite/DiscussionForumPage + Article + Person + ProfilePage.
- Open Graph + Twitter card على الصفحات المهمة.
