- الموقع: شات درر العرب (https://www.iraqia-chat.com)
- المرجع: s.txt §11، §12، §13، §64

## الوضع الحالي (مبني على فحص فعلي)
- HTML خام من CDN (GitHub Pages) بلا خطوة تصيير على العميل.
- لا JavaScript على الصفحات المُدارة (831 صفحة) ⇒ لا حجب تصيير.
- جميع صور الغرف تحمل `width/height` + `loading="lazy"` ⇒ قليل/عدم وجود CLS.
- CSS واحد رئيسي `assets/premium.min.css` (Mimified) + `seo.min.css`.
- عدد الأصول: JPG=955، PNG=99، JS=21، CSS=74.

## مبادئ ملزمة
- Maximum HTML / CSS، Minimal JavaScript؛ لا JS بلا وظيفة حقيقية (§11).
- Mobile-first، بلا Overflow أفقي، مقاسات لمس مناسبة، خطوط عربية واضحة (§12).
- صور مضغوطة بأبعاد صريحة وlazy للأسفل، preload لما يستحق فقط (§13، §37).

## قياس (§64) — اختبار التوسّع
تم تنفيذ اختبار توليد صفحات للتحقق من جدوى التوسّع (الأرقام في
`_audit/final-test-summary.md`). الخلاصة: البنية الثابتة تتحمّل آلاف الصفحات
دون وقت بناء لأن النشر مجرد نسخ ملفات؛ عنق الزجاجة هو حجم المستودع/الصور لا التصيير.

## توصيات
- عند الرغبة: توليد صور WebP/AVIF بصيغة بديلة عبر `<picture>` دون كسر الروابط.
- إبقاء CSS حالي؛ أي إضافة تُصغَّر.
- لا إضافة مكتبات JS؛ البحث يعمل بملف صغير أصلي واحد.
